## 1. Verdict in one paragraph

The manuscript is a **framework + theory + simulation** study that was written, labelled, and typeset as if it reported measured experiments on real data. Two independent audits — one numeric/traceability, one mathematical — establish that (a) **no model was ever trained**, (b) **no bioactivity dataset was ever read**, and (c) **several load-bearing mathematical claims are false as stated**. All three conditions are incompatible with the Sacred `/truth` Law. The corrections below make the document honest without deleting the author's work: results are re-labelled as simulation outputs, invalid theorems are withdrawn *in place* (retained for provenance), and a formal defect register (Appendix F) records every open problem.

## 4. Mathematical audit — claims withdrawn

Full detail is in **Appendix F** of the corrected PDF. Summary:

| Claim | Status | Why |
|---|---|---|
| Theorem 1 bound `O(σ/√M + √(dr/N))` | **withdrawn** | `1/√N` is backwards — a class containing all *N* adapters must have a bound growing with *N*. `1/√M_dom` is dropped in two restatements, so the expression does not vanish as *M*→∞. |
| "strictly tighter than monolithic by *k/N*" | **withdrawn** | Never proved; *k* is an expert index elsewhere; contradicts the `103×` claim by ~50×. |
| `103×` covering reduction | **withdrawn** | Upper bound divided by lower bound; numerator counts one rank-*r* matrix in one layer, denominator counts `L·d²` for the whole model. Consistent counting gives **≈4–7×**. |
| Proposition 3 — "strictly convex" CRR loss | **withdrawn (false)** | KL(p‖q\*) is convex in *p*, but *p* = softmax(W_r·u/τ) is not affine in W_r. For the paper's own q\* = (0.95, 0.05), the second derivative is **negative at p = 0.25** — the exact router-blindness initialisation. Loss is concave where optimisation starts. |
| Lemma 2 — "L_lip ≤ 1.0" | **constant corrected** | Hypothesis ‖u‖₂ ≤ 1 is false for LayerNorm output (‖u‖₂ ≈ √d ≈ 35.8). True constant is ‖u‖₂/τ. Also: proof never uses low-rank structure; bounds full softmax *p*, not the top-K gate *g*. |
| Algorithm 1 projection | **flagged** | `Σ_k M_k` = all-ones, so `Σ_k M_k ⊙ ∇` is a **no-op**. Per-domain loop required. |
| Proposition 4 — "invariant for all t ≥ 0" | **scope corrected** | Proof assumes plain GD; the specified optimiser is AdamW with weight decay, so masked rows decay as (1−ηλ)^t. Logits only — not the softmax distribution, not accuracy. |
| Parameter count `0.58M / 0.089%` | **flagged** | Matches one rank-16 adapter pair + router. The 13-layer corridor with three rank-*r* projections ≈ **6.39M (0.98%)**. |

**What actually survives:** the softmax Jacobian steps, the closed-form KL gradient, the mean-value-theorem step, exact logit-level invariance under the mask, and the `103` arithmetic itself (`√(16/(33·1280²)) = 1/102.76` — the number is right, the comparison is meaningless).
